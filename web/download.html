Installation media

One ISO per architecture. Write it to a USB stick of 4 GB or more, or attach it to a virtual machine. The installer refuses any disk under 16 GB and takes the whole disk it is given.

This is a developer preview of software that has not been released. It installs and boots, and it is not finished: Entra ID sign-in does not work, and on x86-64 neither Secure Boot nor rollback has been tested. Use a virtual machine or a spare disk.

Check what you downloaded

Every ISO is published with its SHA-256 sum. The sums are also collected in a SHA256SUMS file beside the images. Comparing them costs a minute and is the only way to tell a truncated download from a complete one.

Windows — PowerShell

Get-FileHash .\OS7-<version>-amd64.iso -Algorithm SHA256

Linux or macOS

sha256sum OS7-<version>-amd64.iso
# or, against the published list:
sha256sum -c SHA256SUMS --ignore-missing

Write it to a USB stick

The image is a hybrid ISO: it is written to the stick as-is, byte for byte. Do not unpack it, and do not let a tool “convert” it.

Windows

Use Rufus, pick the ISO, and when it asks, choose DD Image mode. The default ISO mode rewrites the boot layout and produces a stick that UEFI will not start.

Linux or macOS

sudo dd if=OS7-<version>-amd64.iso of=/dev/sdX bs=4M status=progress oflag=direct
sync

/dev/sdX is the whole device, not a partition, and everything on it is lost. On macOS the device is /dev/rdiskN and the flag is conv=sync.

Turn Secure Boot off to install. The setup medium’s bootloader is unsigned, so firmware with Secure Boot enabled will refuse to start it. The installed system boots with Secure Boot on, against the Microsoft UEFI CA — switch it back on after the install.

Before you start

System requirements

OS/7 inherits Ubuntu 26.04’s requirements and adds its own: a UEFI-only boot path, a ZFS root that likes memory, and a LUKS2 header whose unlock is pinned at 512 MiB so that install time and boot time agree.

Or build it yourself

The ISO is built in a privileged Docker container, so the prerequisites are Docker and GNU make. Always build through the Makefile: it asks git on the host for the three facts the version number is made of, which a container inside a git worktree cannot work out for itself. 

git clone https://github.com/upinblue/OS7.git
cd OS7
make build-amd64        # on an x86-64 host, about 20 minutes
make build-arm64        # on an Apple Silicon Mac, about 5 minutes

amd64 cannot be built on Apple Silicon: debootstrap cannot unpack a Debian root filesystem under Docker’s x86 emulation. On Windows, build inside WSL 2 and clone into the Linux filesystem rather than /mnt/c. Full instructions are in the repository README.
