# Every PowerShell function OS/7 adds

**185 functions in six modules.** This is the reference: what exists, which
layer it belongs to, and what each one does.

It was **generated by asking the modules**, not written from memory — every name
and every one-line description below is the function's own `.SYNOPSIS`, read out
of `Get-Command` and `Get-Help` on 2026-08-28. If a function is missing from
this file it is missing from the product, and if one here does not exist the
generation would not have produced it.

| [`powershell/Net/`](../powershell/Net/) | generic | 11 |

## The rules this surface obeys

These are [POWERSHELL-SURFACE-PLAN.md](POWERSHELL-SURFACE-PLAN.md)'s decisions,
restated here because they explain the shape of every table below.

**The `OS7` prefix is canonical (P1).** `Get-OS7Service`, never `Get-Service` —
even where the name is free on Linux today. A free name is not free for ever,
and our parameter sets will never match Windows': a cmdlet that took the same
name and accepted a third of the parameters would turn a copied script into one
that half-works, which is worse than one that fails on its first line.

**Subsystems get a generic module; OS/7 policy sits above it (P2, P8).** The
five generic modules know their subsystem and nothing about OS/7 — they would
run on any Ubuntu host. `powershell/OS7/` is the product on top.
`installer/testing/check-layering.py` holds four rules that stop the product
layer reaching past its generic one, each at a baseline that may fall and may
not rise.

**What PowerShell already does on Linux is not rebuilt (P4).** There is no
`Get-OS7Process`, no `Get-OS7FileHash`, no `Restart-OS7Computer`. The test for
admission is not "would this be convenient" but "does an operator otherwise have
to type a Linux command".

**Every cmdlet asks the thing itself (P5).** `netplan apply` returns 0 for a
configuration that brings nothing up; `systemctl is-active` says `active` for a
unit in a restart loop; `useradd -m` exits 0 and does nothing when the home
exists. An exit code is a diagnostic, not an answer.

**Two fields, never one: configured and effective (P6).** Anything with both a
stored intent and a running reality reports both, separately. The interesting
machine is the one where they disagree, and a merged field would hide exactly
that machine.

**Secrets are never serialised (P7).** Any cmdlet taking one takes a
`[securestring]` or `[pscredential]`, never a `[string]`, and never puts it
where `ConvertTo-Json` can reach it. Three self-tests assert this with canaries.

## `Zfs` — the storage layer

Knows OpenZFS and nothing about OS/7. Checked against **recorded real ZFS
output** shipped beside it (`Test-ZfsModule`, 75 assertions).

**Reading**

| | |
|---|---|
| `Get-Zpool` | The ZFS storage pools on this system. |
| `Get-ZpoolStatus` | Pool health with the vdev tree as objects, not as indented text. |
| `Get-ZfsDataset` | Filesystems, volumes and snapshots, as objects. |
| `Get-ZfsSnapshot` | Snapshots, as objects. |
| `Get-ZfsProperty` | Properties of a dataset, one object per property, with their source. |
| `Get-ZfsSpace` | Where a dataset's space has actually gone. |
| `Format-ZfsSize` | A byte count as a human-readable binary size. |

**Creating and changing**

| | |
|---|---|
| `New-Zpool` | Create a storage pool. |
| `New-ZfsDataset` | Create a filesystem or a volume. |
| `New-ZfsSnapshot` | Snapshot a dataset. |
| `New-ZfsClone` | Create a writable clone of a snapshot. |
| `Convert-ZfsClone` | Promote a clone so it no longer depends on its origin. |
| `Rename-ZfsDataset` | Rename or move a dataset. |
| `Set-ZfsProperty` | Set properties, and report what ZFS then holds. |
| `Clear-ZfsProperty` | Return a property to its inherited or default value. |
| `Mount-ZfsDataset` | Mount a dataset, and confirm **from ZFS** that it is mounted. |
| `Dismount-ZfsDataset` | Unmount a dataset. |
| `Import-Zpool` / `Export-Zpool` | Import a pool; export one so it can be imported elsewhere. |
| `Start-ZpoolScrub` | Start, pause or stop a scrub, and report what the pool then says. |

**Destroying** — each irreversible, each `ConfirmImpact = 'High'`

| | |
|---|---|
| `Remove-ZfsDataset` · `Remove-ZfsSnapshot` · `Remove-Zpool` | Destroy a dataset, a snapshot, a pool. |
| `Restore-ZfsSnapshot` | Roll a dataset back to a snapshot. Destructive. |
| `Clear-ZpoolLabel` | Remove ZFS's label from a device, so a pool can be created on it again. |
| `Test-ZfsModule` | Check the module against recorded real ZFS output, or against real ZFS. |

## `Directory` — LDAP, Kerberos and realm membership

New on 2026-08-27. It exists because `System.DirectoryServices.Protocols` ships
**inside** PowerShell 7.6.5 on Linux and works there, while
`System.DirectoryServices` (ADSI) loads and then throws *"not supported on this
platform"*. One of those two is a foundation and the other is a trap, and only a
measurement separates them.

**The connection**

| | |
|---|---|
| `Connect-DirectoryServer` | Open a bound connection and return a session object. TLS by default — sign-and-seal cannot be enabled on this platform, so 636 is the only credential path it has. |
| `Disconnect-DirectoryServer` | Close a session's connection. Safe to call twice. |
| `Get-DirectoryWhoAmI` | Ask the **server** who it thinks this connection is (RFC 4532). |
| `Get-DirectoryRootDse` | The server's own description of itself: naming contexts, functional levels, the DC's name. |

**Objects**

| | |
|---|---|
| `Search-Directory` | Run one LDAP search, **following the pages to the end**. |
| `New-DirectoryEntry` · `Set-DirectoryEntry` · `Remove-DirectoryEntry` · `Move-DirectoryEntry` | Create, modify, delete, move or rename one object. |
| `Set-DirectoryPassword` | Set a password through `unicodePwd`, and refuse over an unencrypted connection **before the wire sees it**. |

**Reading what a directory sends** — every one returns `$null` on failure rather
than guessing, and every numeric parse is culture-invariant

| | |
|---|---|
| `Get-DirectoryAttributeValues` | Every value of one attribute, **always an array** — empty when absent. |
| `Get-DirectoryAttributeScalar` | The first value, or `$null`. Never a character. |
| `ConvertFrom-DirectoryFileTime` | An AD FILETIME as a DateTime. `0` and `Int64.MaxValue` both mean *never*, and neither means 1601. |
| `ConvertFrom-DirectoryGeneralizedTime` | An LDAP generalized time as a DateTime. |
| `ConvertFrom-DirectorySid` | An `objectSid` byte array as `S-1-5-21-…`. |
| `ConvertFrom-DirectoryGuid` | An `objectGUID` byte array as a GUID string. |
| `ConvertTo-DirectoryInt64` | An LDAP integer, parsed invariantly. |
| `Get-DirectoryAccountControl` | Decode `userAccountControl` into named flags. |
| `Get-DirectoryErrorMeaning` | Turn an `LdapException` into a sentence. AD answers **49 for nine different things**, and only a three-hex-digit sub-code separates "wrong password" from "locked out". |
| `Get-DirectoryLdapException` | Dig the real exception out of the wrapper PowerShell puts around it. |

**Escaping** — two RFCs, two rules, deliberately two functions

| | |
|---|---|
| `ConvertTo-DirectoryFilterValue` | Escape a value for a search filter (RFC 4515). An asterisk in a name is not a wildcard. |
| `ConvertTo-DirectoryDnValue` | Escape one RDN value (RFC 4514). A comma in a name addresses a different object. |
| `ConvertTo-DirectoryDomainDn` | `os7.test` → `DC=os7,DC=test`. |
| `Split-DirectoryDn` | Split a DN into components, honouring escapes. |

**Realm membership** — the join half, which starts processes rather than opening
sockets

| | |
|---|---|
| `Join-DirectoryRealm` | Join this host to a Kerberos realm with `adcli`, and write sssd's configuration. The password goes in on **stdin**, never in an argument. |
| `Remove-DirectoryRealm` | Leave a realm: delete the computer account and remove the keytab. |
| `Update-DirectoryRealm` | Renew this host's machine account password and keytab. |
| `Get-DirectoryRealmConfiguration` | What this host is **configured** to believe about a realm, read off disk. |
| `Get-DirectoryKeytabPrincipal` | The principals in a keytab, read with `klist -k`. A file of the right name proves nothing. |
| `New-DirectorySssdConfiguration` | The text of an `sssd.conf`. A **pure function**, so it can be checked without a domain. |
| `Get-DirectoryIdentityResolution` | Whether the name service can resolve a directory account — the only question that proves a join works. |
| `Get-DirectoryTicket` · `New-DirectoryTicket` · `Remove-DirectoryTicket` | The Kerberos credential cache: list, obtain, destroy. |
| `Test-DirectoryTool` | Whether a program this module needs is present. Never throws. |
| `Test-DirectoryModule` | Check the module against recorded output from a real directory. |

## What is deliberately not here

**Rebuilt from PowerShell (P4):** `Get-OS7Process`, `Get-OS7FileHash`,
`Restart-OS7Computer`, `Get-OS7Date`, `Test-OS7Connection`, `Get-OS7Credential`,
`Get-OS7Clipboard`. All measured present and working on Linux PowerShell; a
wrapper would be a second, slightly different behaviour beside a working one.

**Group Policy.** No GPO engine exists for Linux. sssd can *enforce*
logon-right GPOs on a joined machine, which is consumption, not administration.

**Anything over RPC or DCOM:** `repadmin`, `dcdiag`, `netdom`, DNS server
management, DHCP, certificate enrolment. No cross-platform client exists.

**Anything through `[ADSI]`.** `System.DirectoryServices` loads on Linux and
then throws. A Windows script that uses it does not port by copying.

**WinRM.** `New-PSSession -ComputerName` exists as a parameter and answers *"no
supported WSMan client library was found"*. SSH-based remoting
(`-HostName`) works and is PowerShell's own, so P4 says it is not rebuilt.

**`Set-TimeZone`.** P1 forbids taking Microsoft's name; the compatibility module
that would resolve it (`OS7.Compat.Windows`, aliases only, each entry driven by
a test) is designed and not built. An admin therefore finds `Get-TimeZone` with
no partner, and that is an open question rather than a decision.

## How to check any of this yourself

```bash
pwsh -c 'Import-Module ./powershell/Zfs/Zfs.psd1       -Force; Test-ZfsModule'
pwsh -c 'Import-Module ./powershell/Net/Net.psd1       -Force; Test-NetModule'
pwsh -c 'Import-Module ./powershell/Time/Time.psd1     -Force; Test-TimeModule'
pwsh -c 'Import-Module ./powershell/Systemd/Systemd.psd1 -Force; Test-SystemdModule'
pwsh -c 'Import-Module ./powershell/Directory/Directory.psd1 -Force; Test-DirectoryModule'
pwsh -c 'Import-Module ./powershell/OS7/OS7.psd1       -Force; Test-OS7Backup'
```

And to regenerate the inventory this file is built from:

```bash
pwsh -c 'Import-Module ./powershell/OS7/OS7.psd1 -Force; Get-Command -Module OS7 | ForEach-Object { "{0}  {1}" -f $_.Name, (Get-Help $_.Name).Synopsis }'
```
